Dense Layer & Output

LayerDense(46, activation="softmax")
Input shape(64,) — from GlobalAveragePooling2D
Output neurons46 — one per character class
ActivationSoftmax (probabilities sum to 1.0)
BiasYes (default — only the Dense layer has bias)
Parameters64 × 46 + 46 = 2,990
Inverted filter progression — Stages go 512→256→128→64 (standard ResNet-18 goes 64→128→256→512). Unusual but achieves 99.48%.
Large stem kernel — 8×8 conv instead of the standard 7×7, adapted for 32×32 input.
No bias in convolutions — use_bias=False throughout; BatchNorm handles the bias term.
Global Average Pooling — Replaces fully connected layers, reducing parameters and overfitting.
Adam optimizer — Default learning rate (1e-3) with sparse categorical crossentropy loss.

Model Code Snippet

def basic_block(x, filters, stride): shortcut = x out = Conv2D(filters, 3, strides=stride, padding="same", use_bias=False)(x) out = BatchNormalization()(out) out = ReLU()(out) out = Conv2D(filters, 3, strides=1, padding="same", use_bias=False)(out) out = BatchNormalization()(out) if stride != 1 or x.shape[-1] != filters: shortcut = Conv2D(filters, 1, strides=stride)(shortcut) shortcut = BatchNormalization()(shortcut) return ReLU()(Add()([out, shortcut]))
